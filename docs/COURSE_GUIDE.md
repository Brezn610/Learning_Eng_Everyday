# Daily Spoken English — Editorial & Sync Guide

## Purpose
Build everyday spoken English fluency for 30-minute natural conversations. Each lesson should take 10–15 minutes, use Chinese explanations and clear American English examples, and prioritize common chunks over difficult words.

## Daily format
1. Topic A naturally leads to Topic B through a relevant detail, reply, or follow-up; no arbitrary topic splicing.
2. 10–14 rounds of original, realistic dialogue with reactions, follow-ups, and natural transition. Explain difficult lines in Chinese.
3. 6–10 spoken phrases with accurate US IPA, Chinese meaning and a short example.
4. Two or three reusable sentence patterns, one or two connected-speech/pronunciation tips, and brief US/UK comparison when useful.
5. Two or three questions in one continuous role-play, encouraging follow-up questions and replies.
6. BBC Learning English source links only after verifying their existence. Don't fabricate episodes, transcripts or links; don't copy full copyrighted material.
7. Avoid repeating recent topic pairs. Keep notes concise and readable.

## Storage
- Daily file: `lessons/YYYY-MM-DD.md`, use local date in Europe/Berlin.
- First check if the dated file already exists. If so, read it and update deliberately; never create duplicates or overwrite blindly.
- Index new lessons in README (fetch the latest SHA first).
- Public repository: omit private identifiers, unpublished research specifics, personal records and contact details. Examples can be fictionalized.
- The exact same educational content should be delivered in ChatGPT and archived in GitHub where practical. If the write fails, send the lesson anyway and clearly report the failure.
- Automated ChatGPT delivery is configured separately. GitHub archive synchronization is not guaranteed merely by the presence of these files; verify each future run.

## Suggested GitHub archival steps
1. Generate and send today's lesson.
2. Check repository `Brezn610/Learning_Eng_Everyday` for today's dated file.
3. Create `lessons/YYYY-MM-DD.md` (or fetch SHA then update when correcting an existing file).
4. Update README lesson index with today's date and topics.
5. Confirm GitHub commit and link to the file. If connector is inaccessible, report that plainly.

## Progress goals
5 minutes of description → 10 minutes of interaction → 20 minutes of storytelling and opinions → 30 minutes of natural conversation.

This repository is independent of BBC Learning English. BBC is an inspiration and listening resource, not a content provider for these original lessons.
