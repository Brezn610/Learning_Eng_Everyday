## 每期有什么

- **Topic A → Topic B：** 两个自然衔接的主/次话题，不硬拼场景
- **Real Conversation：** 10–14 轮原创双人对话，练习接话、追问、自然转场
- **Useful Chunks：** 6–10 个高频口语词/语块，美式 IPA、中文含义、例句
- **Pronunciation：** 1–2 个连读、弱读或其他自然语流现象
- **Conversation Skills：** React → Pick up a detail → Ask a follow-up
- **Speaking Challenge：** 2–3 个连贯追问，练习实时表达
- **Listening：** 仅在来源已核实的情况下附 BBC 官方节目链接

## 学习方法

1. **听/读 3 分钟：** 跟读对话，观察 Topic A 怎样自然切换到 Topic B。
2. **学 4 分钟：** 把本期 2–3 个高频句型各造一个自己的句子。
3. **说 5 分钟：** 不看稿回答结尾的问题，并主动反问。
4. **回顾 2 分钟：** 选出最有用的一句写到自己的词汇笔记中。

## 长期口语目标

`5 分钟描述 → 10 分钟互动 → 20 分钟解释观点 → 30 分钟自然交流`

这里的 30 分钟是沟通训练目标，不直接等同于某个 CEFR 等级。

ChatGPT 每日定时课程安排在 **Europe/Berlin 08:00**。目标是**同一份课程同时出现在 ChatGPT 和此仓库**。

- 自动向 GitHub 写入需要定时任务在执行时能够访问已连接的 GitHub 操作；**是否能在无人值守情况下持续写入，需由后续实际运行确认**。
